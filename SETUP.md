# R2 Bucket Setup for lee.app.nz

This guide walks through setting up your R2 bucket to serve your static site at lee.app.nz.

## Prerequisites

- Cloudflare account with R2 enabled
- Domain (lee.app.nz) added to Cloudflare
- R2 API credentials set as environment variables:
  - `R2_ACCESS_KEY_ID`
  - `R2_SECRET_ACCESS_KEY`

## Automatic Setup

Run the setup script:

```bash
npm run setup:bucket
```

## Manual Setup (if automatic fails)

### 1. Create R2 Bucket

1. Go to [Cloudflare Dashboard](https://dash.cloudflare.com) → R2
2. Create a new bucket named `lee-app-nz`
3. Location: Choose your preferred region

### 2. Configure Custom Domain

1. In the R2 bucket settings, go to "Settings" tab
2. Under "Public access", click "Connect Domain"
3. Enter `lee.app.nz`
4. Cloudflare will automatically:
   - Create the necessary DNS records
   - Set up SSL certificate
   - Configure routing

### 3. Configure Bucket for Static Website

1. In the bucket settings, enable "Public access"
2. Set the following:
   - Index document: `index.html`
   - Error document: `404.html` (optional)

### 4. CORS Configuration (Optional)

If you need CORS support, add this policy in the bucket settings:

```json
[
  {
    "AllowedOrigins": ["*"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

### 5. Deploy Your Site

Once the bucket is configured:

```bash
# Build and deploy
npm run deploy
```

### 6. (Optional) Advanced: Cloudflare Worker for Better Routing

For proper index.html handling on subdirectories, create a Worker:

1. Go to Workers & Pages in Cloudflare Dashboard
2. Create a new Worker
3. Use the code from `worker.js` (generated by setup script)
4. Bind your R2 bucket to the Worker:
   - Variable name: `BUCKET`
   - R2 bucket: `lee-app-nz`
5. Add custom domain route for `lee.app.nz`

## Deployment Commands

```bash
# One-time setup
npm run setup:bucket

# Build the site
npm run build:site

# Deploy to R2
npm run deploy

# Development
npm run dev
```

## Environment Variables

Create a `.env` file (don't commit this!):

```bash
export R2_ACCESS_KEY_ID="your-access-key-id"
export R2_SECRET_ACCESS_KEY="your-secret-access-key"
export R2_CLOUDFLARE_TOKEN="your-api-token"  # Optional, for automatic DNS setup
```

Then source it before deploying:

```bash
source .env
npm run deploy
```

## Troubleshooting

### DNS not working
- Check that lee.app.nz is added to your Cloudflare account
- Verify the CNAME record points to: `lee-app-nz.f76d25b8b86cfa5638f43016510d8f77.r2.cloudflarestorage.com`
- DNS propagation can take up to 24 hours (usually much faster)

### 404 errors on subdirectories
- Deploy the Cloudflare Worker for proper routing
- Or ensure all links include `.html` extension

### Access denied errors
- Verify R2 credentials are correct
- Check bucket has public access enabled
- Ensure custom domain is properly connected
